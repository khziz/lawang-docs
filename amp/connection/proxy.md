# Connection Proxy

**Proxy** adalah perantara (intermediary) antara client dan server. Client tidak berkomunikasi langsung dengan server tujuan, tetapi request-nya melewati proxy terlebih dahulu.

## Gambaran penggunaan

Dipakai bila request ke server tujuan harus melewati perantara.

## Konfigurasi

{% hint style="info" %}
Materi sumber saat ini hanya menjelaskan **konsep** connection ini. Langkah pengisian field connection, endpoint, dan service belum tersedia, jadi bagian tersebut perlu dilengkapi setelah materinya ada.
{% endhint %}

Alur umumnya sama dengan connection lain: **Connection → Endpoint → Service**. Lihat [Konsep dasar](../konsep-dasar.md).
