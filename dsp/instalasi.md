# Instalasi dan kebutuhan sistem

## Kebutuhan sistem

| Komponen | Minimum | Rekomendasi |
|---|---|---|
| Sistem operasi | Ubuntu 18.04 / Windows 10 | Ubuntu 20.04 / Windows 11 |
| RAM | 2 GB | 4 GB atau lebih |
| CPU | Dual Core 1,6 GHz | Dual Core 2,4 GHz atau lebih |
| Disk | 512 (HDD) / 128 (SSD) | 256 (SSD) atau lebih |
| Browser | Versi 20 ke atas | Chrome / Firefox terbaru |

## Prasyarat

Pasang terlebih dulu:

1. Docker
2. Golang
3. PostgreSQL
4. PgAdmin
5. KMT

## Setup awal

1. Instalasi **Lawang Distribution**
2. **Pull docker image**
3. Konfigurasi **console** dan **core engine**
4. **Buat instance database** Lawang
